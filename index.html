Speed and power are only starting values written into the LightBurn layer. Every laser and material differs, so run a test on scrap first.

In LightBurn: use File → Open for the .lbrn2 (Import drops the layer settings), keep the image layer on Pass-through, and do not resize the image. Each pixel is already one laser dot at the chosen resolution, so resizing changes the dot pitch and blurs the dither.
